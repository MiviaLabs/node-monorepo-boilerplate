# Contributing

Thanks for contributing to MiviaLabs Node Monorepo Boilerplate.

## Development

1. Install Node.js 24 or newer and pnpm.
2. Follow the setup steps in [README.md](README.md).
3. Keep changes focused and include tests for behavior changes.
4. Run the relevant lint, typecheck, and test commands before opening a pull request.

## Pull requests

- Explain the problem and the approach.
- Document configuration or migration changes.
- Never include secrets or real personal data.
- Use conventional commit messages, for example `feat: add ...` or `fix: ...`.

Please open an issue before large architectural changes so the direction can be discussed publicly.
