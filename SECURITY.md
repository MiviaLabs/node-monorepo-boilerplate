# Security policy

## Supported versions

The default branch is the only actively maintained version of this starter repository. Deployments should pin dependencies and review the security configuration for their environment.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, contact the maintainers privately through the repository owner's GitHub profile and include:

- a description of the issue and its impact;
- steps to reproduce or a minimal proof of concept;
- affected files, versions, or configuration; and
- any suggested mitigation.

Do not include credentials, personal data, or other sensitive material in the report.
